# local-slm-ollama-lab-
Local SLM App with Ollama is a local AI benchmarking dashboard that compares small language models like Qwen, Mistral, Llama, Phi, and Gemma. It shows quantization, RAM/VRAM usage, tokens/sec, latency, and offline deployment readiness.  Demo:  https://local-slm-ollama-lab.vercel.app
