# Local SLM Ollama Lab — Showcase Snapshot

This repository is a presentation snapshot with a workflow image. The runnable browser dashboard is maintained in the [canonical Local SLM Ollama Lab repository](https://github.com/kalyan870/local-slm-ollama-lab), which includes its HTML, CSS, JavaScript, and Ollama API client.

The original project notes list a [hosted showcase](https://local-slm-ollama-lab.vercel.app/); availability may change. A hosted static page cannot automatically connect to a visitor's `localhost` Ollama server—see the canonical repository for the connection and CORS notes.

This snapshot does not contain the app source or local setup files. Use the canonical repository to run and maintain the project.
